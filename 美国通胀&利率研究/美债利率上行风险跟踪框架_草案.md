# 美债利率上行风险持续跟踪框架（草案 v0.1）

> 目的：在"政策性利率开始快速向市场性利率传导、美债加速上行"这一关键拐点出现前，实现**提前预警**。
> 依据：君君（投知君君买方视角）两篇视频《美联储议息前夜，买方如何理解加息影响？》《买方怎么看美联储加息？不猜结论，靠模型》的原文框架。
> 状态：框架草案，供讨论确认，未进入数据采集/实现阶段。

---

## 一、核心逻辑提炼（严格基于视频）

### 1.1 三个基础判断

1. **债券价格 = 两种利率**：政策性利率（=央行态度，即美联储态度）+ 市场性利率（=市场对未来流动性的预期，含利率预期 + 资产负债表扩张/收缩预期）。
2. **加息的影响必须"传导"**：政策性利率不能直接导致市场风险偏好收缩/扩张，必须**传导到市场性利率**才有效；且**市场化利率永远领先于政策性利率**——它在"猜"政策利率未来 3/6/9/12 个月会不会"加速上行"。
3. **美债收益率变动可切分为三块**：政策性利率因素 + 中远期通胀因素 + 期限溢价（期限溢价"是个框，啥都能往里装"，不可精确分析，一般免掉，只盯前两块）。

### 1.2 传导三拍（核心预警机制）

君君给出的"从加息到金融紧缩"的传导过程，是整条预警链的骨架：

| 拍次 | 特征 | 政策:通胀占比 | 含义 |
|---|---|---|---|
| **第一拍** | 政策利率预期先被调上（短端领先，早于联储实际动作，price in 两三次加息） | **8:2** | 正常"回摆"阶段（如本轮"去年降快了往回修"），**不构成紧缩威胁** |
| **第二拍** | 政策利率预期到位后，市场转向监控"市场化利率/通胀传导" | **8:2 → 5:5** | **黄色预警**：需要开始盯通胀本身，不能再简单说"加息没事" |
| **第三拍** | 通胀预期与政策利率**同时上行**，通胀部分在美债定价中反超 | **6:4（通胀>政策）** | **红色预警**：美债加速上行，流动性紧缩压力最大 |

> 关键区分：君君反复强调"**加速加息（压通胀）≠ 加息（调节奏）**"。本轮两年期上行 80-90BP 中，政策性因素占 70+BP、通胀仅十几 BP，属于"降快了往回修"的第一拍，不是通胀失控。**预警的目标就是识别 8:2 何时滑向 5:5、再滑向 6:4。**

### 1.3 通胀失控是"加速加息"的前置条件

第三拍（通胀与政策利率同涨）的前提是通胀预期抬头、甚至通胀失控。因此视频给出了**左侧领先监控链**（用来提前预判"通胀预期是否会抬头"）：

```
原油冲击(台阶性/一过性判断)
   → 原油→化工链传导强度（化工品涨幅 vs 原油涨幅、库存消耗、能否顺价）
   → 商品通胀 → 服务型通胀的"工资-通胀螺旋"（工资增速 + 失业率 + 职位空缺数）
   → 通胀预期（breakeven/TIPS）抬头
   → 传导占比 8:2 → 5:5 → 6:4
```

## 二、四维度跟踪模板

### 维度一：政策利率（政策性利率）

- **定义**：美联储的"态度"——联邦基金目标利率及其路径指引（点阵图、声明措辞、加/降息节奏）。
- **观测指标**：
  1. 联邦基金目标利率区间（当前 3.75%–4.00%）
  2. FOMC 点阵图 / 声明措辞（"研究研究"式模糊 vs 方向性承诺）
  3. 联邦基金期货隐含的未来加息次数（CME FedWatch 口径）
  4. 2 年期美债收益率（政策敏感的短端锚）
- **上行加速触发信号（君君"三板斧"）**：
  1. 联储承认"之前看错了"（历史案例：21Q4 承认看错、22Q1 猛加）
  2. 预告下季度要"猛加"
  3. 加息终点不确定（"不知道加到哪天"）
  → 本质：从"预防性/表演性加息"切换为"追通胀式加速加息"。
- **预警阈值（草案）**：
  - 联邦基金期货隐含未来 3 个月加息 ≥ 2 次；
  - 或 2 年期收益率月度上行斜率显著陡峭化（相对 10 年不动/微动，即"熊陡"）。
  - ⚠️ 具体数值需历史回测校准（视频未给精确数字）。

### 维度二：市场利率（含通胀预期）

- **定义**：市场对未来流动性的预期，**领先于**政策利率，是政策是否"传导成功"的直接观测面。
- **观测指标**：
  1. 利率掉期/联邦基金期货曲线（3/6/9/12 个月）——君君点名"第一时间能反应过来"的工具
  2. 通胀预期：TIPS 盈亏平衡通胀率 breakeven（5Y / 10Y）
  3. 美债收益率曲线斜率（10Y–2Y，陡峭/平坦）
  4. 原油期货期限结构（WTI 近远月价差，判断原油冲击是"台阶性/一过性"还是"趋势性"）
- **上行加速触发信号**：
  - 掉期曲线开始 price in 政策利率"加速上行"（而非匀速加息）；
  - breakeven 抬头 → 通胀部分在美债定价中占比上升；
  - 曲线由"平坦"转"陡峭"，且由短端（2Y）带动。
- **预警阈值（草案）**：
  - breakeven 10Y 站稳某关键位（需校准，可参考历史分位 P75/P90）；
  - WTI 远端（如 27 年 6 月合约）定价显著上移并带动近月 → 原油从"一过性"转"趋势性"（当前远端约 70 多，是"一过性"的锚）。

### 维度三：期限溢价

- **定义**：长端债券持有者因"期限长、久期长"、对不确定性（财政赤字、债券供给、政策不确定性）要求的额外补偿；等价于"财政部与联储在流动性和发行上要给我的补贴"。
- **观测指标**：ACM 期限溢价（纽约联储 Adrian-Crump-Moench）、Kim-Wright 期限溢价，主看 10Y。
- **上行加速触发信号**：期限溢价**快速抬升**——即"框"里装进的不可建模不确定性在累积（君君把前两块分不清的东西都推给它，因此它是"残差项"）。
- **预警阈值（草案）**：10Y ACM 期限溢价由负转正 / 显著抬升（需校准）。
- **定位**：不是主动预警维度，而是**兜底/交叉验证项**——当维度一、二都无法解释长端上行时，若期限溢价跳升，提示"财政/供给/政策不确定性"冲击，需要单独定性研判。

### 维度四：市场传导压力（核心预警维度）

- **定义**：政策利率 → 市场利率的**传导程度**，用美债收益率变动的"政策:通胀"归因占比量化。
- **观测指标**：
  1. 美债收益率变动归因切分（政策性 vs 通胀 vs 期限溢价）——君君的"切分模型"
  2. 政策:通胀占比（8:2 / 5:5 / 6:4）
  3. 实际利率 = 名义利率 − 通胀预期（君君："实际利率是政策性利率减通胀"）
- **上行加速触发信号（三拍）**：见 1.2 表。
- **预警阈值**：
  - **8:2（政策主导）＝ 绿色**：正常回摆，无需恐慌；
  - **5:5 ＝ 黄色**：传导启动，转入"盯通胀本身"模式；
  - **通胀占比反超政策（6:4）＝ 红色**：美债加速上行、流动性紧缩压力最大。

## 三、维度间的传导关系与相互验证

**主传导链**（自上而下）：
```
政策利率(维度一)
   ↓ 加速加息
市场利率/通胀预期(维度二)  ←—— 左侧领先信号：通胀监控链(工资螺旋/化工顺价/二手车)
   ↓ 占比切换
市场传导压力(维度四) → 美债加速上行预警
期限溢价(维度三) = 残差兜底，异常跳升单独研判
```

**相互验证规则**：
1. **维度四的"政策:通胀占比"必须与维度一、二交叉验证**：政策占比高时应看到 2Y 领涨、10Y 不动（维度一主导）；通胀占比抬升时应同步看到 breakeven 上行（维度二确认）。
2. **期限溢价跳升而维度二不动** → 提示非利率、非通胀的结构性冲击（财政赤字、供给、地缘），需切换到定性研判，不能套用"三拍"框架。
3. **"熊陡"（短端带动的陡峭化）是维度一→二的传导信号；"牛陡/通胀陡"需区分**：若 10Y 因通胀预期而陡峭化，则已进入维度四黄色区。
4. **原油期限结构是"通胀预期抬头"的第一道闸**：远端定价不动=一过性冲击（君君当前判断），远端上移=趋势性冲击→通胀预期有上行风险。

### 需手工维护 / 滞后 / 口径差异的关键点

1. **收益率归因切分（维度四核心）**：无现成统一口径，君君未公开"切分模型"的具体权重与算法。→ 需自建（见下替代方案）。
2. **期限溢价**：只能靠模型估计（ACM / Kim-Wright），存在模型间口径差异 + 周度滞后。→ 用官网数据 + 固定单一模型口径。
3. **工资增速 WGT**：多口径（unweighted/weighted、3 个月/12 个月移动平均），此前项目实测 iFinD 的 12 个月口径与"6%→3%"的说法存在约 1 个百分点差异。→ 锁定口径（建议 3 个月 MA、未加权，与视频口径对齐）。
4. **利率掉期曲线**：国内数据商覆盖不全。→ 需确认，或用联邦基金期货曲线 + 2Y 收益率作代理。
5. **化工链顺价**：品种选取与"宽口径油系化工品"的定义需手工固化。→ 固定一个可复现的品种篮子 + 加总涨幅口径。
6. **美国消费数据**：君君明言"我们也做不了，直接找海外投行买服务包"。→ 用公开代理（密歇根消费者信心、零售销售、信用卡消费指数）替代。

## 五、视频未讲清、需外部理论补充的框架细节

以下为君君框架中一笔带过、但实施时必须补齐的环节（**只补技术细节，不改主逻辑**）：

1. **"切分模型"的具体实现**：君君只说"存在一些模型可以把美债定价按类别分开"，未给算法。→ 采用纽约联储 ACM 仿射期限结构模型（Adrian-Crump-Moench, 2013）作标准版，其输出天然分解为"预期利率 + 期限溢价"，与君君"政策/通胀 vs 期限溢价"两分法对齐；简化版用"2Y 变动 = 政策，breakeven 变动 = 通胀"。
2. **breakeven ≠ 纯通胀预期**：breakeven = 名义收益率 − TIPS 收益率 = 通胀预期 + 通胀风险溢价 + 流动性溢价差。君君把 breakeven 当通胀预期用是简化，实施时应知悉这一偏差（可用调查类通胀预期如密歇根 5-10 年通胀预期交叉校验）。
3. **实际利率口径**：君君"实际利率 = 政策性利率 − 通胀"。严格讲，市场实际利率可由 TIPS 收益率直接观测；政策含义上的实际利率 = 名义利率 − 通胀预期。两者需区分，TIPS 实际收益率是更干净的观测。
4. **期限溢价不可直接观测**：需用无套利模型估计，这也是君君说它"是个框/玄学"的数学原因。
5. **曲线形态术语**：君君"陡峭/平坦"，实施时需区分熊陡（短端带动，=政策传导）、熊平、牛陡等，避免误判。

## 六、待讨论确认的开放问题（供对齐）

1. **归因切分模型选型**：用"ACM 标准版"还是"2Y/breakeven 简化版"？这决定维度四的可复现精度。
2. **预警阈值校准**：8:2/5:5/6:4 是君君的口语区间，是否需要回测历史加息周期（94/95、04、15-18、22-23）把比例阈值、breakeven 分位、期限溢价正负校准成可执行数值？
3. **掉期数据源**：需确认 Wind / iFinD 是否有 3/6/9/12 个月 SOFR/OIS 掉期曲线；若无，是否接受用联邦基金期货 + 2Y 代理？
4. **跟踪频率**：日度盯盘（价格类）+ 月度更新（基本面类）的混合节奏是否合适？与已有"通胀压力温度计月度更新"自动化的关系？
5. **通胀维度复用**：是否把乐嵘"四因子"（WGT/粘性/弹性 CPI/通胀广度）并入本框架维度二的领先信号层？
6. **预警输出形态**：最终要的是一个"三色灯"状态面板（绿/黄/红 + 当前占比读数），还是含归因拆解的完整报告？
