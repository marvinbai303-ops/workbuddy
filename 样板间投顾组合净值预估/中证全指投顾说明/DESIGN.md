# DESIGN.md · 中证全指投顾说明（两页）

命中预设风格：**商务咨询风**（design-principle.consulting.md）。面向投顾客户的数据论证页，权威、数据密集、结构化分析。

## 沿用咨询风母版（微调项已声明）

- 画布 1280×720；页面左右 padding 56。
- B 标题块：y=44 起，Action Title 30px Bold Navy 左对齐；标题底下 8px 处 1px 深色分割线；本篇标题单行约 46px 高。
- C 内容区：分割线下 12px 起；主视觉（matplotlib 数据图表）占 C 区 ≥85%。
- D 页脚：底部 y≈666–700，左 Source 13px 灰，右页码 `N / 2` 13px 灰。

## 色彩（≤4 主色 + 中性）

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| Navy 主色 | `#061F32` | 标题、结论句、页码强调 |
| 红（涨/最强/事件） | `#C0392B` | 图内事件标注、最强行业、结论强调数字 |
| 绿（跌/最弱） | `#177B57` | 图内最弱行业 |
| 浅蓝 | `#99BDED` | 图内成交额面积 |
| 中性灰 | `#8a8a8a` / `#E7E6E6` | Source、脚注、分割线辅助 |

页面映射：白底 ≥70%；Navy（标题+图线）≈15%；红/绿仅出现在图表数据与结论数字上（合计 ≤8%）。禁金色、正红底、渐变装饰。

## 字体

`Arial, "PingFang SC", "Microsoft YaHei", sans-serif`

| 层级 | px | 用途 |
| :-- | :-- | :-- |
| Action Title | 30 Bold | 每页主标题（完整结论句） |
| 结论洞察 | 20 / 关键数字 Bold 红或 Navy | 图下结论行 |
| 图内文字 | 由 matplotlib 渲染（10–15px 等效） | 坐标轴/标注 |
| Source / 页码 | 13 | 页脚 |
