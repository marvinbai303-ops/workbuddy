# DESIGN.md — 科技温度计周报

## 画布
1280 × 720，三区：A 标题块 0–120px ／ B 内容区 120–660px ／ C 页脚条 660–720px（右下页码 NN/02）

## 色板（≤4 hex + 中性色）
- 主色：`#1F3A6E` 深蓝（标题块、表头）
- 辅色：`#2F6FED` 蓝（温度计线、强调数字）
- 强调：`#D93636` 红（涨幅/关键数字，金融涨红惯例）
- 辅助语义：`#16A34A` 绿（40 度阈值/低温区）
- 中性：文字 `#1A1D26`，次级 `#7B8494`，边框 `#E5E8EE`，底 `#F7F9FC`
- 字体：PingFang SC（标题 600，正文 400）

## 页面映射
- Page1：标题块（深蓝）→ KPI 读数条 3 卡（当前/上周/边际，大数字 40px，边际为红）→ 主图（近一年温度计+TMT 双轴，占 B 区 ~55%）→ 底部归因一句话（浅蓝底横条）
- Page2：标题块（深蓝）→ 主图（事件触发全期图，占 B 区上半 ~48%）→ 统计表（3 行数据 + 表头，深蓝表头白字）→ 底部结论条（米黄警示底）
- 两页版式不同：P1 竖向三段式（KPI→图→句），P2 上图下表式。
